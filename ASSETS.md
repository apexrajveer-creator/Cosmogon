# Assets and licensing

Cosmogon ships **no third-party art**. Everything visual is generated:

| Asset | Source | License |
|---|---|---|
| Planet, cloud, ring and city-light textures | Generated at runtime from the simulation (`render/bake.rs`) | Project license |
| Skybox | Generated at startup (`render/sky.rs`) | Project license |
| Shaders | Original WGSL in `crates/cosmogon/src/render/shaders` | Project license |
| App icon | Generated by `scripts/make_icon.py` | Project license |
| UI fonts | egui's bundled defaults (Ubuntu-Light, Hack, Noto Emoji, emoji-icon-font) | Ubuntu Font Licence, MIT/Bitstream, OFL |
| Earth relief (`crates/cosmogon_sim/data/earth_elevation.bin`) | NOAA NCEI **ETOPO5** 5-arc-minute global relief (land + bathymetry), box-filtered to 2048×1024 by `tools/process_etopo.py` | U.S. Government work, public domain. Source: https://www.ngdc.noaa.gov/mgg/global/relief/ETOPO5/ |
| Solar System data | Published orbital elements and physical parameters (JPL/IAU), facts | Not copyrightable data |

Any future imported data (e.g. NASA/USGS elevation maps) must be recorded here with its source and license
before it is committed.

## Mars MOLA overview relief and coverage

`crates/cosmogon_sim/data/mola/` contains NASA PDS MGS MOLA 4ppd topography/count grids, provider
PDS4 XML labels and processing/source metadata. PDS archived datasets are public domain according
to the provider FAQ; attribution and evidence are in `data/SOURCE_REGISTRY`. Exact source values
are endian-converted without resampling. This data does not license unrelated mission photographs.
