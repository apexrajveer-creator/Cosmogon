# Recorded graph navigation design

Prepared before implementation, 2026-10-09, following replay checkpoint `cb7e339`. Master directive §63 calls for zoom, pan, cursor, units, log scale, CSV export and saved layouts. Habitat graphs already retain actual selected observations and protected complete numeric exports, but always show the whole recording and cannot retain a display layout. General research graphs have separate range/preferences foundations; reuse their presentation/data separation, without altering Universe, samples or analysis exports.

Build one bounded app-only graph model/renderer for ordinary single/comparison trajectories and paired effects. Time-window fractions refer explicitly to the current complete aligned time extent, including both comparison recordings. Use real coordinates for irregular stored times; nearest-point selection is limited to actual visible A observations. A selected point outside the viewport stays selected and is labeled; centering it changes only the display. Zoom/pan have buttons as well as pointer affordances, and full-range reset. A window with no supported observations gets explicit unavailable state, not invented axes/values.

Linear axes must retain negative quantities. Positive-only log10 masks nonpositive values without replacing them with tiny numbers; retain counts/selected original values and make that omission explicit. Add a separately named signed piecewise log scale with an explicit user threshold in current units: y/t inside |y|≤t, sign(y)(1+log10(|y|/t)) outside. Tick labels invert to original physical units. It is a display mapping, not a transformed-data analysis or uncertainty model. [Matplotlib's official axis documentation](https://matplotlib.org/stable/users/explain/axes/axes_scales.html) supplies primary software context for explicit axis scales/thresholds, and [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section5/pmc52.htm) explains the positive domain of ordinary logarithmic transforms. The renderer and navigation policies here are engineering choices; no new plotting dependency is needed.

A strict bounded schema stores metric/effect/alignment/window/scale/threshold choices as presentation-only layout. It is explicitly reusable on a different recording; fractions adapt to that recording's complete aligned extent and do not assert a shared epoch/source. Native protected import/export and explicit local preference save preserve invalid/newer existing files. CLI startup import is preflighted before GPU; no silent ignored-context flags. Request-time metadata includes exact layout, actual time extent/window, visible index/value support and scale omissions so captures can be checked against retained data. Existing complete CSV/JSON exports remain raw and full, independent of viewport/scale.

Acceptance: boundary-preserving zoom/pan and selection on irregular times; positive/log/signed-scale inverse tests; windows with no samples; unsupported and zero/negative values; source-independent display-layout roundtrip/future/input/output refusal; native ordinary/paired/comparison/snapshot layouts and a normal 30–60 second run. Keep sources/analyses/recordings untouched and the golden unchanged. Broader research graph integration, manual accessibility verification and the complete directive remain unfinished.
