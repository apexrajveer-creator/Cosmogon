# Habitat recordings: product mechanism and acceptance

Prepared 2026-10-08 after finite electrolysis and CO₂ reduction. The native habitat panel currently presents snapshots while the shared CLI already produces real trajectories. Directive phase 9/16 asks equations, measurements and experiments usable from student to researcher. A native reader/graph is the next connected build: inspect existing numeric evidence without rerunning or mutating an open world.

Evidence: repository habitat::export writes original definition, report, samples JSON/CSV, exact initial/final saves and a format/model/source manifest. Existing research recordings and terrain studies establish protected bounded local imports, independent recorded views and actual photo metadata. No new physical law or scientific validity claim is introduced.

Build a bounded shared reader for native and CLI inspection. Check manifest format/schema/model, sample count/time ordering/horizon, each stored habitat/config/chemistry budget, exact endpoint saves and habitat identities, initial/final fingerprints, definition/report consistency and optional source/model/version requirements. Fingerprints are state identity, not cryptographic authenticity; no field calibration inferred. Import calculation commits only after success; malformed data preserves the previous view. Recorded identity/geography/configuration remain distinct from whichever live world is open.

Native Recordings tab opens a bundle folder, selects a stock/power/pressure/temperature metric, draws actual points with axes and gap handling for unavailable intervals, allows pointer and slider sample selection, shows world vs completed interval times and exact selected results/settings/constraints. No interpolation or extrapolation. Native photo metadata retains recording source identity, metric and actual selected row. A bounded CLI habitat-inspect command uses the same reader and emits summary/validation information. Comparison/uncertainty/live native recording may follow, but initial reader cannot claim those workflows complete.

Acceptance: exact valid snapshot/trajectory imports including existing uncoupled and reaction bundles; endpoint/fingerprint/source corruption and malformed/future/oversized inputs rejected; observational read leaves world untouched; failed native import preserves previous rows/selection; native capture data equals shared inspected rows; graph axes/selected values/blank intervals are visually inspected. Required full tests, clippy, package/captures and ordinary run precede checkpoint. No save/golden change.
