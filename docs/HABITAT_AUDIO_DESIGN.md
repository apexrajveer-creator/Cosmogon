# Habitat equipment sound: evidence and mechanism

Prepared before implementation, 2026-10-08. This continues the directive's native audio environment foundation and habitat state feedback. It does not finish cabin acoustics, terrain atmosphere sound, or first-person interiors.

NASA's [Acoustics and Noise Control](https://www.nasa.gov/directorates/esdmd/hhp/acoustics-and-noise-control/) describes spacecraft fans, pumps and valves as hardware sound sources, and requires hardware acoustic measurements. NASA's [Quiet Space Fan research](https://www.nasa.gov/general/nasa-quiet-space-fan-research-to-benefit-commercial-space-stations/) identifies ventilation and equipment cooling fans as cabin noise sources and explains that design changes alter noise at a given operating performance. Neither source establishes a generic conversion from simulated electrical watts to sound pressure or pitch.

Engineering inference: equipment state can support an educational listening preview if the mapping is labeled as designed sonification. Do not invent calibrated decibels, motor RPM, cabin geometry, acoustic safety ratings, faults, or sound transmission through vacuum.

The optional listener explicitly selects one live habitat's interior preview in Sound & Alerts. Selection does not move the camera or alter the Universe. Default listening context is exterior space. Realistic mode keeps external cinematic effects silent but can play this explicitly selected interior preview. Historical recordings never become live sources. Selection clears on session generation changes, deletion and leaving observation.

Read only the last completed, supported habitat interval and its saved interval configuration. The engine's fixed allocation order allows exact reconstruction of served base, scrubber and recycler watts from total delivered power. Optional reactors already report their own delivered watts. Map these fractions to bounded fan, air-processor, water-processor and reactor textures; a powered idle processor may hum even when no material flows. Zero served power means no sound; retained chemical stocks do not imply running equipment. Missing configuration or unsupported intervals remain silent and explain why. Pausing holds the last completed interval, explicitly labeled in the interface.

One native streaming source shares bounded atomic target levels with the audio thread. Smooth changes per sample, bound oscillator phases, avoid simulation RNG and asset churn. A separate persisted environment mixer level preserves old preference defaults. Master mute, photo mode, capture and explicit quiet mode suppress playback. Existing notification routing remains independent.

Export a fixed eight-second mono PCM preview plus a source report into a new folder, without overwriting existing files. Use the same decoder and source mapping as live playback. The export is an inspectable presentation artifact, independent of the user's mixer, not a simulated acoustic measurement. Include exact habitat state/configuration/budget, world/completed times, mapping version, units and limitations. A short worker performs file work outside the UI thread. Validate causal power starvation, disabled equipment, historical configuration, unsupported intervals, finite bounded PCM, smoothing, context reset, preference compatibility and protected exports; inspect actual native captures and run the packaged app normally before checkpointing.
